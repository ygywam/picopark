# 🐱 피코파크 웹 멀티플레이어 (PICO PARK Web)

스팀의 인기 협동 게임 **피코파크(PICO PARK)**처럼, 웹 브라우저 링크 하나로 최대 30인 이상의 학생들이 한 방에 모여 서로의 머리 위에 올라타 인간 탑을 쌓고, 스위치를 눌러주며 열쇠를 얻어 탈출하는 **실시간 멀티플레이 웹 협동 플랫포머 게임**입니다.

---

## 🌟 주요 특징

1. **대규모 50개 협동 스테이지 풀 탑재**:
   - 👥 **2인 듀오 챌린지 (1~10)**: 스택킹 기초, 스위치 릴레이, 밧줄 번지 등 (기존 스테이지 완벽 보존)
   - 🔺 **3인 삼총사 챌린지 (11~20)**: 3단 사다리, 3색 삼각 스위치, 3인 삼각 로프 번지 등
   - 🔷 **4인 스쿼드 챌린지 (21~30)**: 4단 피라미드, 4방향 동시 스위치, 4인 초대형 블록 밀기 등
   - ⭐ **5~6인 모둠 챌린지 (31~40)**: 5인 성벽, 5인 스위치 오케스트라, 6인 더블 스쿼드 등
   - 🏆 **8~30인 학급 올스타 단체 챌린지 (41~50)**: 학급 전원 인간 피라미드, 학급 메가 밧줄 체인, 골리앗 블록 총력전 등
2. **🎲 럭키 랜덤 스테이지 추첨**:
   - 대기실에서 버튼 하나로 현재 접속 인원에 딱 맞는 스테이지를 무작위로 추첨하여 수업의 긴장감 극대화!
3. **🎯 대표 선수 출전 & 벤치 응원/교체(체인지) 시스템**:
   - 30명이 다 같이 뛸 수도 있고(`전원 출전`), 스테이지 필요 인원(예: 4명)만큼 `대표 선수`를 선발하여 출전시킬 수 있습니다.
   - **벤치(관전) 학생**: 폰 화면에서 👏 박수, 🔥 불꽃, 🎉 폭죽, 🚀 로켓 응원 버튼을 눌러 교실 화면에 응원 이모지를 팡팡 띄웁니다!
   - **선수 체인지**: 잘 안 풀리거나 차례를 바꿀 때 선생님이 상단의 **[🔄 선수 교체]** 버튼을 누르면 벤치 학생과 즉시 바통 터치!
4. **교사용 대형 화면 QR 코드 자동 생성**:
   - 선생님이 교실 대형 프로젝터나 전자칠판에 방을 열면 선명한 초대 QR 코드가 표시됩니다.
   - 학생들은 스마트폰 카메라로 QR을 스캔하기만 하면 방 코드가 자동 입력되어 1초 만에 입장합니다.
5. **모바일 가로모드 최적화 & 듀얼 플레이 모드 선택**:
   - **🎮 [패드 전용 모드 (교실 스크린 보기)]**: 폰 화면 전체가 큼직한 가상 게임패드로 변신하여 학생이 폰 화면 대신 교실 대형 칠판/스크린에 시선을 고정하고 콘솔 패드처럼 조작할 수 있습니다.
   - **📱 [개인 화면 모드 (내 폰 화면 보기)]**: 학생 폰 화면에서도 게임 화면을 직접 보며 반투명 가상 버튼으로 조작합니다.
6. **피코 로프(인간 밧줄 번지점프) 물리 엔진**:
   - 절벽 위에서 버티고 아래로 매달려 열쇠를 낚아채는 피코파크 특유의 로프 물리를 완벽 지원합니다.
7. **Vercel & GitHub 배포 최적화**:
   - 백엔드 서버 비용이나 설정 없이 WebRTC P2P 기반으로 동작하여 Vercel 무료 플랜에서 영구 호스팅 가능합니다.

## 🚀 GitHub 및 Vercel 배포 방법 (1분 완성)

### 1단계: GitHub 저장소에 올리기
1. [GitHub](https://github.com/)에서 새 레포지토리(Repository)를 생성합니다.
2. 터미널 또는 Git GUI 툴에서 이 폴더의 코드를 커밋하고 푸시합니다.
```bash
git init
git add .
git commit -m "feat: 피코파크 웹 멀티플레이어 완성"
git branch -M main
git remote add origin https://github.com/사용자아이디/저장소이름.git
git push -u origin main
```

### 2단계: Vercel에서 원클릭 배포하기
1. [Vercel](https://vercel.com/)에 로그인하고 **[Add New...] → [Project]**를 클릭합니다.
2. 방금 푸시한 GitHub 저장소를 선택하고 **[Import]**를 누릅니다.
3. 빌드 설정(Build Settings)은 기본값(정적 호스팅) 그대로 두고 **[Deploy]** 버튼을 클릭합니다.
4. 약 10초 후 배포가 완료되면 발급된 도메인 링크(예: `https://pico-park-web.vercel.app`)로 전 세계 누구나 접속할 수 있습니다!

## 🎮 플레이 방법

1. **방장(호스트)**:
   - 닉네임을 입력하고 **[🏠 새 방 만들기]**를 클릭합니다.
   - 화면에 표시된 **6자리 방 코드**(예: `PK7A2F`)를 복사하여 친구들에게 공유합니다.
   - 모든 친구들이 대기실에 들어오면 **[🚀 게임 시작하기]**를 누릅니다.
2. **참가자**:
   - 닉네임과 공유받은 **6자리 방 코드**를 입력하고 **[입장하기]**를 누릅니다.
3. **스테이지 클리어 조건**:
   - 혼자서는 못 닿는 곳은 서로의 머리 위에 올라타 점프하여 열쇠를 획득합니다.
   - 열쇠를 든 플레이어가 문에 닿으면 문이 열립니다.
   - **방에 있는 모든 플레이어가 문 안으로 쏙 들어가야** 다음 스테이지로 넘어갑니다!

## 📁 프로젝트 구조
- `index.html`: 게임 메인 캔버스 및 로비 화면
- `vercel.json`: Vercel 정적 사이트 호스팅 설정
- `css/style.css`: 라이트 모드 UI 테마
- `js/lib/peerjs.min.js`: 로컬 내장 WebRTC P2P 라이브러리 (교내망 차단 방지)
- `js/network.js`: P2P 룸 생성/참가 및 실시간 동기화
- `js/physics.js`: 2D 플랫포머 및 스택킹(탑 쌓기) 물리
- `js/gimmicks.js`: 인원수 비례 열쇠, 발판 스위치, 밀기 상자, 문
- `js/stages.js`: 스테이지 1~3 레벨 맵 데이터
- `js/player.js`: 30가지 고유 색상 및 귀여운 표정 렌더링
