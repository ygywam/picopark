# 🐱 피코파크 웹 멀티플레이어 (PICO PARK Web)

스팀의 인기 협동 게임 **피코파크(PICO PARK)**처럼, 웹 브라우저 링크 하나로 최대 30인 이상의 학생들이 한 방에 모여 서로의 머리 위에 올라타 인간 탑을 쌓고, 밧줄로 매달리며 열쇠를 얻어 탈출하는 **실시간 멀티플레이 웹 협동 플랫포머 게임**입니다.

GitHub 및 Vercel 무료 정적 호스팅에 특화되어 백엔드 서버 비용이 전혀 들지 않으며, 학교 교내망 환경에서도 외부 의존성 차단 없이 100% 매끄럽게 동작합니다.

---

## 🌟 주요 특징

### 1. 🎬 피코파크 라이브 플레이 인트로 튜토리얼
- 처음 접속 시 실제 인게임 캐릭터와 물리 엔진을 활용한 4단계 라이브 시연 데모(달려오기 ➡️ 4단 탑 쌓기 ➡️ 공중 열쇠 획득 ➡️ 밧줄 매달려 문 탈출 ➡️ 팡파레)가 캔버스 애니메이션으로 생생하게 펼쳐집니다.
- **[🎮 게임 시작하기]**, **[⏩ 건너뛰기]**, **[🚫 다시 보지 않기]**를 지원하며, 로비 하단에서 언제든 **[🎬 오프닝 인트로 다시보기]**를 누를 수 있습니다.

### 2. 📜 [특별] 십계명 모으기 10단계 챌린지 (Stage 51~60)
- **성경 개역개정 출애굽기 20장**의 제1계명부터 제10계명까지를 테마로 한 최소 5인 필수 협동 특별 스테이지!
- **말씀 빈칸 정답 단어 열쇠 & 가짜 열쇠 엔진**: 각 계명의 성경 빈칸에 알맞은 정답 단어 열쇠(신들, 우상, 이름, 안식일, 부모, 살인, 간음, 도둑질, 거짓 증거, 탐내지)로만 문이 열리며, 가짜 단어 열쇠는 문에서 거부 효과음과 함께 튕겨나갑니다.
- **십계명 두 석판 봉헌 엔딩**: 10단계를 모두 완수하면 모세의 두 돌판에 제1~10계명이 황금빛으로 새겨지는 감동의 특별 피날레 연출이 펼쳐집니다.

### 3. 👥 대규모 60개 협동 스테이지 풀 (인원수별 맞춤형)
- 👥 **2인 듀오 챌린지 (1~10)**: 2단 스택킹 기초, 2인 스위치 릴레이, 2인 밧줄 번지 등
- 🔺 **3인 삼총사 챌린지 (11~20)**: 3단 사다리, 3색 삼각 스위치, 3인 삼각 로프 번지 등
- 🔷 **4인 스쿼드 챌린지 (21~30)**: 4단 피라미드, 4방향 동시 스위치, 4인 초대형 블록 밀기 등
- ⭐ **5~6인 모둠 챌린지 (31~40)**: 5인 성벽, 5인 스위치 오케스트라, 6인 더블 스쿼드 등
- 🏆 **8~30인 학급 올스타 단체 챌린지 (41~50)**: 학급 전원 인간 피라미드, 학급 메가 밧줄 체인, 골리앗 블록 총력전 등
- 📜 **[특별] 십계명 모으기 챌린지 (51~60)**: 최소 5인 필수 협동 성경 말씀 탐험 퍼즐 10단계

### 4. 🎵 Web Audio API 4채널 탐험 BGM 시퀀서 & 음량 조절
- 외부 mp3 파일 다운로드 없이 브라우저 내장 Web Audio API로 리드 멜로디, 맑은 화음 아르페지오, 통통 튀는 베이스, 경쾌한 비트를 실시간 합성합니다.
- **4가지 고유 테마**: 🌲 초원 탐험, 🏰 신비한 유적, ⚡ 긴박한 탈출, 🎉 피코 행진곡
- **단계별 자동 전환 & 상단 툴바**: 스테이지 분위기에 맞춘 자동 곡 전환과 함께 상단에서 `[🎵 테마 변경]`, `[🔉 -]`, `[현재 볼륨 %]`, `[🔊 +]`, `[🔇/🔊 음소거]`를 자유롭게 조절할 수 있습니다.

### 5. 🎯 대표 선수 선발 출전 & 벤치 응원/교체(체인지) 시스템
- 30명이 다 같이 뛸 수도 있고(`전원 출전`), 스테이지 필요 인원(예: 4명)만큼 `대표 선수`를 선발하여 쾌적한 턴제/로테이션 수업을 진행할 수 있습니다.
- **벤치(관전) 학생**: 폰 화면에서 👏 박수, 🔥 불꽃, 🎉 폭죽, 🚀 로켓 응원 버튼을 눌러 교실 화면에 응원 이모지를 실시간으로 띄웁니다.
- **선수 체인지**: 잘 안 풀리거나 차례를 바꿀 때 선생님이 상단의 **[🔄 선수 교체]** 버튼을 누르면 다음 순번 학생들과 즉시 바통 터치합니다.

### 6. 📱 교사용 대형 화면 QR 코드 자동 생성 & 듀얼 컨트롤
- 선생님이 교실 대형 프로젝터나 전자칠판에 방을 열면 선명한 초대 QR 코드가 표시됩니다.
- 학생들은 스마트폰 카메라로 QR을 스캔하기만 하면 방 코드가 자동 입력되어 1초 만에 입장합니다.
- **🎮 [패드 전용 모드 (교실 스크린 보기)]**: 폰 화면 전체가 큼직한 가상 조이스틱으로 변신하여 교실 대형 스크린에 시선을 집중할 수 있습니다.
- **📱 [개인 화면 모드 (내 폰 화면 보기)]**: 학생 폰 화면에서도 게임 화면을 직접 보며 플레이할 수 있습니다.

### 7. 🪢 피코 로프(인간 밧줄 번지점프) 물리 엔진
- 플레이어들이 밧줄로 연결되어 한 명이 절벽 위에서 버티고 다른 친구가 절벽 아래로 번지점프하듯 매달려 공중의 열쇠를 낚아채는 피코파크 특유의 로프 물리를 완벽 지원합니다.

### 8. 🔒 학교 환경 맞춤 설계 & 개인정보 0% 수집
- 학생 실명, 학번, 회원가입 절차 없이 임의의 닉네임과 30가지 고유 색상만 부여되며, 방 종료 시 어떤 데이터도 저장되지 않는 완전 무결한 교육용 도구입니다.

## 🚀 GitHub 및 Vercel 배포 방법 (1분 완성)

### 1단계: GitHub 저장소에 올리기
1. [GitHub](https://github.com/)에서 새 레포지토리(Repository)를 생성합니다.
2. 터미널 또는 Git GUI 툴에서 이 폴더의 코드를 커밋하고 푸시합니다.
```bash
git init
git add .
git commit -m "feat: 피코파크 웹 멀티플레이어 완성"
git branch -M main
git remote add origin https://github.com/사용자아이디/저장소이름.git
git push -u origin main
```

### 2단계: Vercel에서 원클릭 배포하기
1. [Vercel](https://vercel.com/)에 로그인하고 **[Add New...] → [Project]**를 클릭합니다.
2. 방금 푸시한 GitHub 저장소를 선택하고 **[Import]**를 누릅니다.
3. 빌드 설정(Build Settings)은 기본값(정적 호스팅) 그대로 두고 **[Deploy]** 버튼을 클릭합니다.
4. 약 10초 후 배포가 완료되면 발급된 도메인 링크(예: `https://pico-park-web.vercel.app`)로 전 세계 누구나 접속할 수 있습니다!
