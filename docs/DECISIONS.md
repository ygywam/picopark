### 2026-11-06 · GitHub 및 Vercel 배포 최적화: WebRTC P2P (PeerJS) 아키텍처 전환
Vercel은 상시 WebSocket 서버(Node.js 상주 프로세스)를 호스팅할 수 없는 서버리스 플랫폼이므로, 백엔드 서버 없이 브라우저 간 초저지연 직접 통신이 가능한 WebRTC DataChannel (PeerJS) 아키텍처로 전환함.
이로써 구글 드라이브 내 `node_modules` 생성 충돌을 원천 해결하고, 외부 서버 비용 0원으로 Vercel 정적 호스팅에 원클릭 배포할 수 있는 초경량 고성능 구조를 확립함. 교내망 CDN 차단을 방지하기 위해 `peerjs.min.js`를 프로젝트 내부에 직접 번들함.

### 2026-11-06 · 양방향 머리 위 스택킹 완벽 연동 및 인원수 비례 맞춤형 스테이지 구조 구축
1. 기존에 호스트 루프에서만 실행되던 `resolvePlayerStacking`을 게스트(학생) 클라이언트 루프에서도 매 프레임 병행 실행하도록 수정함. 이로써 학생도 선생님 머리 위를 즉각 발판으로 인식하고 안정적으로 올라타 점프할 수 있는 완전한 양방향 스택킹을 완성함.
2. `stages.js`를 정적 데이터에서 접속 인원수($N$)를 파라미터로 받는 `getStageData(stageIndex, playerCount)` 생성기 함수로 전면 리팩토링함:
   - 1인 접속: 1인 점프 튜토리얼 (혼자서 100% 클리어 가능).
   - 2인 접속: 2단 탑 쌓기 전용 열쇠 높이(`y = 430`) + 1명이 머리를 밟고 절벽에 먼저 올라가 스위치를 밟아주면 아래 친구를 위한 도우미 발판이 내려오는 2인 맞춤형 협동 퍼즐로 재구성.
   - 3인 이상: 3단 이상 다단 탑 쌓기 및 다인 협동 기믹으로 자동 확장.
3. 스위치로 활성화된 브릿지(움직이는 발판) 및 밀려난 상자를 플랫폼 배열에 동적으로 포함시켜 플레이어가 발판 삼아 밟고 올라설 수 있도록 물리 엔진을 강화함.

### 2026-11-06 · js/physics.js 중복 중괄호 구문 오류 패치 및 버튼 응답 정상화
1. `js/physics.js`의 `drawRopes` 함수 끝에 중복 닫는 괄호 `}`가 남아 클래스가 조기 종료되고, 그 뒤의 `static resolvePlayerStacking`이 클래스 바깥에서 파싱되면서 발생하던 `SyntaxError: Unexpected strict mode reserved word`를 완전 해결함.
2. 이 구문 오류로 인해 `main.js`의 ES 모듈 import 체인이 중단되어 로비의 '새 방 만들기' 버튼 이벤트 리스너가 등록되지 않던 문제를 정상화함. 모든 JS 모듈의 문법 검증(Node.js `--check`)을 통과하고 `공유용/` 폴더에 동기화 완료함.
