# 아키텍처 구조 (ARCHITECTURE)

## 1. 개요
본 프로젝트는 GitHub 및 Vercel 정적 호스팅(Static Hosting)에 원클릭으로 배포할 수 있는 **WebRTC P2P 기반 실시간 멀티플레이어 웹 게임**입니다.
별도의 유료 백엔드 서버나 복잡한 프레임워크 의존성 없이, 방장(호스트) 브라우저와 참가자 브라우저 간의 직접 데이터 채널(WebRTC DataChannel)을 통해 최대 30인 이상의 캐릭터 좌표와 상호작용을 초저지연(0.01~0.03초)으로 동기화합니다.

├─ css/
│  └─ style.css               # 부드러운 화이트 톤의 라이트 모드 반응형 UI
├─ js/
│  ├─ lib/
│  │  └─ peerjs.min.js        # 교내망 CDN 차단 방지용 내장 WebRTC 라이브러리
│  ├─ network.js              # P2P 룸 생성(6자리 코드), 참가, 메시지 중계 동기화
│  ├─ input.js                # PC 키보드 & 모바일 가상 조이스틱/점프 통합 입력기

## 3. WebRTC P2P 룸 및 동기화 메커니즘
1. **호스트(방장)의 룸 생성**: 방장이 "방 만들기"를 누르면 영문/숫자 6자리 고유 룸 코드(예: `PICO77`)가 발급되며, 호스트의 브라우저가 게임 세션의 권위 서버(Authoritative Host) 역할을 수행합니다.
2. **참가자 P2P 직결**: 참가자가 닉네임과 6자리 룸 코드를 입력하면 WebRTC DataChannel을 통해 호스트와 직접 연결됩니다.
3. **상태 동기화**:
   - 각 플레이어는 자신의 입력/위치 벡터를 호스트에게 초당 30회 전송합니다.
   - 호스트는 스테이지 내 물리 기믹(열쇠 획득, 발판 스위치, 밀린 상자 위치)과 모든 플레이어 좌표를 통합하여 전체 클라이언트에게 브로드캐스트합니다.
4. **인원수 비례 자동 조절**: 호스트는 방에 입장한 실제 인원수(N)를 기준으로 스테이지 기믹 난이도와 클리어 조건을 실시간 계산합니다.
